# 序描 SeqSketch

面向有序矢量素描研究的本地浏览器绘图工具，首版基于 [Paper.js 0.12.18](https://github.com/paperjs/paper.js) 的 MIT 开源曲线拟合与几何能力，使用 React、TypeScript 和 Vite 构建。

本仓库包含应用源码、功能测试、依赖清单、数据格式说明和便携启动器源码。参与者作品、导出数据、浏览器存储、日志、已构建网站及 Node.js 可执行文件不纳入版本管理。内置人像是代码生成的合成示例，不是采集样本。

## 启动

安装 Node.js 22.12 或更新的 LTS 版本，在本目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的本机网址，默认是 http://127.0.0.1:5173 。每次采集使用同一个浏览器、网址和端口，以访问同一份本机作品库。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是构建后的网站。导出文件需要配套的本地服务，因此请使用上述开发/预览服务或免安装版启动器，不能直接双击 `index.html`，也不能仅部署静态文件来使用导出功能。多人采集时，每台电脑运行自己的工具，分别导出和汇总。

从 GitHub 获取源码后，按上述命令安装依赖并启动。`portable/` 中的启动文件用于组装 Windows 免安装包，不是源码仓库根目录的启动入口；免安装包的操作说明见 [portable/使用说明.md](./portable/使用说明.md)。

## 已实现

- 数位笔或鼠标自由手绘，不使用压感；白色 800 × 1000 画布，固定 1.5 px、不透明黑色线条。
- 每次落笔由 Paper.js 拟合成一段或多段三次贝塞尔曲线。小于 0.75 画布像素的手势不记录。
- 逐段选择、移动、删除，以及拖动或输入四个控制点坐标。编辑保留该曲线的 ID 和创建顺序。
- 擦除整段曲线；一次操作可撤销。保留最近 60 次几何操作的撤销记录。
- 平移、缩放、逐段顺序预览，以及按创建顺序排列的曲线列表。
- 本机自动保存、作品库、工程打开与备份、训练 JSON 和 SVG 导出。
- 作品库逐件删除；删除当前作品后打开其他作品，库中已无其他作品时创建空白作品。
- “贝塞尔曲线”和“一次落笔”两种记录模式，同步切换序列列表、回放和导出，并随工程保存。
- 在导出窗口填写导出文件夹，工具记住位置；文件通过本地服务保存，同名文件更新。
- 内置合成人像示例，数据始终带有 `source: "example"`，用于试用和验证。

暂不包含参考图、账号、云端汇总、多人协作、图层、局部擦除、拆分/合并曲线或完整操作日志。手指用于平移和双指缩放，绘画使用鼠标或数位笔。

## 采集流程

1. 在作品侧栏填写匿名作者编号和作品名称。同一个人始终使用同一个作者编号；多人共用电脑时需要手动切换编号。
2. 新建作品，选择顶部记录模式并绘制。选择“曲线节点”或点击右侧序列列表可以修改曲线；落笔模式可从“落笔内曲线”下拉框选择具体段。P0/P3 是端点，P1/P2 是控制点。
3. 播放底部顺序预览，确认最终保留线条的顺序。
4. 在“导出数据”中填写导出文件夹的完整路径，例如 `D:\素描数据`，再导出“训练数据”和“完整工程”；需要预览或后续矢量处理时再导出 SVG。路径属于运行本地服务的电脑，工具会记住该位置并创建尚不存在的文件夹。同名文件更新；两种模式的训练数据和 SVG 分别带有 `.curve` 或 `.stroke`，可以同时保留。
5. 将各电脑的导出文件集中备份。正式训练时排除 `source: "example"`，按 `sampleId` 去重，并建议按 `artistId` 划分训练、验证和测试集。

自动保存写入当前浏览器的 IndexedDB，并非已经生成磁盘备份。清除浏览器数据、使用无痕模式或换浏览器可能使本机作品库不可用。每件作品都应导出完整工程，不应把唯一数据副本留在浏览器里。

## 数据约定

完整说明见 [DATA_FORMAT.md](./DATA_FORMAT.md)。

- 曲线模式以一段贝塞尔曲线作为一个训练元素；落笔模式以一次按下到抬起作为一个训练元素，包含一段或多段曲线。
- 训练 JSON 1.1 使用 `sequenceUnit` 标记模式，`lines` 表示训练序列，平铺的 `curves` 字段继续保留。
- 输出仅含最终保留下来的曲线，以最初创建顺序排序；编辑不会把旧曲线排到最后。
- 删除后 `sequence` 连续重新编号，`creationOrder` 保留原始编号，因此允许有空缺。
- 训练 JSON 坐标以宽、高分别归一化，左上角为原点，X 向右、Y 向下。控制点可以超出 `[0, 1]`，不应直接截断。
- 完整工程保留最初采样点，包括后来被删除曲线所属落笔的原始输入。采样点不是编辑后的几何，也不构成完整编辑历史。
- 编辑相邻两段中的一段不会自动修改另一段，允许最终段间出现间隙。落笔分组描述历史输入，不保证编辑后几何连续。
- 顺序预览按当前模式逐条显示，不包含后来删除的线，也不重放撤销或修改过程。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 手绘 / 选择 / 节点 / 擦除 / 平移 | P / V / A / E / H |
| 临时平移 | 按住空格，或鼠标中键 |
| 缩放 | Ctrl 或 Command + 滚轮 |
| 撤销 / 重做 | Ctrl 或 Command + Z / Shift + Z |
| 保存工程 / 打开工程 | Ctrl 或 Command + S / O |
| 删除选中曲线 | Delete 或 Backspace |
| 微移选中曲线 | 方向键，按住 Shift 每次移动 10 px |
| 取消当前手势或选择 | Escape |

## 验证与限制

核心自动测试覆盖拟合端点与方向、创建顺序、删除过滤、工程校验、SVG 转义、示例标记及撤销恢复。运行 `npm test` 可重复检查。

单件工程上限为 12,000 段曲线、12,000 次落笔、600,000 个采样点，导入文件上限 64 MB。数量上限用于防止异常数据，不代表在所有电脑上都能流畅处理到该规模。

这是用于试采集的首版。正式采集前，应让少量参与者在实际数位板、浏览器和电脑上试画，检查排线手感、拟合精度和导出结果。尚未进行真实数位板或课堂规模的验证。拟合容差当前固定为 1.8 画布像素，应在正式批量采集前确定，避免中途改变采集口径。

## 开源依赖

选择基于开源绘图库定制界面，而不是大幅修改通用矢量编辑器，是为了直接控制研究数据的身份、顺序和保存语义。Paper.js 提供成熟的几何和拟合能力，其余界面与数据层均位于本项目 `src/` 中。

主要依赖：Paper.js、React、React DOM、Lucide React。许可证见 [THIRD_PARTY_NOTICES.md](./public/THIRD_PARTY_NOTICES.md) 及各依赖目录中的许可证文件；打包时会同时附带这些声明。
