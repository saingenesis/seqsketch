在另一台电脑上开始使用

免安装版适用于 Windows 10/11 的 64 位 Intel/AMD 电脑。使用较新版本的 Chrome 或 Edge，不需要安装开发环境，运行时无需联网。

  1. 把整个“顺序矢量素描”文件夹复制到新电脑。通过压缩包传输时，先完整解压。
  2. 双击启动工具.cmd，浏览器会自动打开绘图工具。
  3. 若没有自动打开，请在浏览器输入 http://127.0.0.1:5317/。
  4. 选择“作品 > 新建作品”，在作品侧栏填写匿名作者编号，然后绘画。
  5. 结束前确认“已在本机保存”，导出完整工程备份，再双击关闭工具.cmd。

每台电脑都要启动自己的工具。关闭网页后服务仍在后台运行；重启电脑后需要重新双击启动。

把作品带到新电脑

复制程序文件夹不会复制浏览器里的作品。 自动保存只是当前浏览器中的本机保存，必须另外备份。

  1. 在原电脑打开作品，选择“导出数据 > 完整工程”。
  2. 将导出的 *.seqsketch.json 文件复制到新电脑。
  3. 在新电脑启动工具，选择“作品 > 打开工程”，即可继续修改。

此前开发版使用 127.0.0.1:5173，本便携版使用 127.0.0.1:5317。两个地址的作品库独立；旧作品也需要导出再导入。更换浏览器、用户配置或使用无痕窗口，也不会看到原作品库。

绘画与数据导出

用数位笔或鼠标手绘，使用固定黑色线宽，不使用压感。点击曲线列表或“曲线节点”可逐段编辑。一次落笔可能生成多段贝塞尔曲线；修改保留原始顺序，删除的曲线不会进入训练数据。

顶部记录模式提供两个选项：“贝塞尔曲线”将每段作为一条线；“一次落笔”将落笔到抬笔产生的所有保留段作为一条线。列表、回放与导出跟随模式切换。落笔模式仍可通过侧栏的“落笔内曲线”选择具体段进行编辑。

导出项用途
完整工程备份、换电脑、重新打开和继续绘画。包含曲线和原始采样点。
训练数据研究使用的有序贝塞尔曲线 JSON，仅包含最终保留的曲线。
矢量作品SVG 矢量文件，用于查看或其他软件处理。

每件作品都建议保存完整工程 + 训练数据。在导出窗口的导出文件夹中填写完整路径，例如 D:\素描数据，再点击导出项。工具会记住位置，并创建尚不存在的文件夹；路径位于运行本地服务的电脑上，换电脑后请重新填写。

文件名自动包含作品名称和作品 ID 的前 8 位，同名文件会更新。两种模式的训练数据和 SVG 分别带有 .curve 或 .stroke，可以同时保留。训练 JSON 不能代替完整工程重新打开。

训练数据 1.1 使用 lines 数组表示当前模式的训练序列，sequenceUnit 标记模式。旧工程可以继续打开，默认采用贝塞尔曲线模式。

删除作品

打开“作品库”，点击作品行右侧的垃圾桶并确认。删除当前作品会打开其他作品；删除最后一件后会创建空白作品。已经导出的磁盘文件不受影响。

多人采集

  • 给每位参与者分配固定的匿名作者编号；共用电脑时记得更换编号。
  • 每台电脑独立保存，定期汇总各自导出的工程和训练文件。当前没有云端同步。
  • 内置人像示例带有 source: "example"，不应作为参与者样本用于训练。
  • 正式收集几百张作品前，先用实际数位板进行少量试画，检查排线、保存和重新打开。

打不开时

先检查文件夹是否完整解压。若提示端口被占用，请关闭之前启动的便携版；若浏览器没自动打开，手动访问固定地址。仍失败时，查看 runtime/server.log。同一台电脑上不要同时启动不同版本；移动文件夹前先关闭服务。

修改源码需要安装 Node.js 22.12 或更新的 LTS 版本，并按 source/README.md 的说明运行。免安装包中的运行组件不含 npm 开发工具。

绘图几何基于 Paper.js。应用开源依赖声明见 app/THIRD_PARTY_NOTICES.md，Node.js 声明见 runtime/NODE-LICENSE.txt。本版尚需真实数位板与正式采集流程验证。
