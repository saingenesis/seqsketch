# 顺序矢量素描：使用与迁移说明

整理日期：2026-09-08。工具名：序描 SeqSketch。版本：0.1.0。

## 一、在另一台 Windows 电脑上使用

适用：Windows 10/11 的 64 位 Intel/AMD 电脑，以及较新版本的 Chrome 或 Edge。无需安装 Node.js、Python 或开发工具，也无需联网。

1. 将整个“顺序矢量素描”文件夹复制到另一台电脑，例如桌面或文档目录。不要只复制“启动工具.cmd”。若通过压缩包传输，必须先完整解压。
2. 双击“启动工具.cmd”。启动窗口会短暂出现，随后打开默认浏览器；本地服务会在后台运行。
3. 浏览器地址固定为 **http://127.0.0.1:5317/**。如未自动打开，请在 Chrome 或 Edge 中输入这个地址。
4. 在工具内选择“作品 > 新建作品”，填写匿名作者编号，开始绘画。
5. 结束前确认右上角显示“已在本机保存”，并导出完整工程备份。之后可双击“关闭工具.cmd”停止本地服务。关闭服务不会删除浏览器中的作品。

本次功能更新后，原来打开的页面按 Ctrl+F5 刷新。顶部“记录模式”可选择“贝塞尔曲线”或“一次落笔”。

每台电脑都需要启动自己的工具。这里的 127.0.0.1 表示“当前这台电脑”，不是共享服务器地址；工具不会自动联网同步数据。关闭网页后服务仍会运行，重启电脑后需重新双击启动。

Windows ARM 电脑没有作为免安装版的目标平台验证。macOS 和 Linux 请使用后文的源码方式。

## 二、把已有作品带到另一台电脑

**复制程序文件夹不会带走浏览器中的自动保存作品。** 程序文件与作品数据是分开的。

1. 在原电脑打开作品，选择“导出数据 > 完整工程”，得到 `*.seqsketch.json` 文件。
2. 把需要迁移的工程文件复制到新电脑。
3. 在新电脑启动工具，选择“作品 > 打开工程”，选择该工程文件即可继续编辑。
4. 用底部顺序预览检查曲线数量和顺序，然后重新导出备份。

开发版默认网址是 http://127.0.0.1:5173/ ，本免安装版使用 5317 端口。两者的浏览器作品库独立。原来画过的作品也需按上述方法导出、导入；并不是换了地址后作品被删除。

自动保存与电脑、浏览器用户配置、网址和端口关联。请一直使用相同的 Chrome/Edge 配置和上述固定网址，不使用无痕窗口。重新分发或更新程序时，先备份作品。

## 三、日常绘画与导出

- 手绘：数位笔或鼠标拖动画线，固定 1.5 px 黑色线宽，不采集压感。
- 节点编辑：选中“曲线节点”，或点击右侧曲线列表，可移动控制点，也可在侧栏输入坐标。
- 删除和撤销：删除的是一整段贝塞尔曲线；一次落笔可能被拟合成多段。
- 顺序：修改曲线保留原始身份和创建顺序；最终导出过滤已删除线条，按最初创建顺序排列。
- 记录模式：“贝塞尔曲线”将一段曲线作为一条记录；“一次落笔”将落笔到抬笔产生的所有保留曲线作为一条记录。模式随作品保存，旧工程默认曲线模式，可随时切换。
- 段内编辑：落笔模式中点击一条落笔，再通过“落笔内曲线”选择具体段；移动、节点编辑和擦除仍以单段曲线为对象。
- 预览：底部播放键按当前模式逐条显示。落笔模式会同时显示这次落笔的全部保留段。
- 删除作品：在“作品库”中点击对应行的垃圾桶，确认后删除。删除当前作品会打开其他作品；删除最后一件后创建新的空白作品。已经导出的磁盘文件不会被删除。
- 保存：每件完成作品都导出“完整工程”和“训练数据”。“已在本机保存”不等于已经备份为磁盘文件。

| 导出格式 | 用途 |
| --- | --- |
| 完整工程 `*.seqsketch.json` | 迁移、备份、重新打开和继续修改，包含原始采样点 |
| 训练数据 `*.dataset.json` | 深度学习研究，只包含有序的最终保留曲线 |
| 矢量作品 `*.svg` | 查看矢量图或与其他软件交换 |

在“导出数据”窗口的“导出文件夹”中填写完整路径，例如 `D:\素描数据`，再点击需要的导出项。工具会记住位置，并创建尚不存在的文件夹。该路径位于运行本地服务的电脑上；换电脑后请重新填写。

文件名自动包含作品名称和作品 ID 的前 8 位，同名文件会更新。两种模式的训练数据和 SVG 分别带有 `.curve` 或 `.stroke`，可以同时保留。不要用训练 JSON 代替完整工程备份。浏览器自动保存仍保存在本机作品库。

训练数据现在为 1.1 版：用 `lines` 数组读取下一条线的序列，用 `sequenceUnit` 区分曲线或落笔。具体字段见“数据格式.md”。

## 四、多人采集建议

1. 给参与者分配唯一且固定的匿名作者编号。多人共用一台电脑时，每换一个人都要检查编号。
2. 各电脑自行画图，每件作品导出完整工程和训练 JSON，定期复制到统一收集目录。
3. 以作品的 `sampleId` 区分作品，以 `updatedAt` 区分重复导出的版本，避免把同一作品重复计数。
4. 内置人像示例和在示例上修改的作品均标记 `source: "example"`，不要纳入参与者训练数据。
5. 正式采集前先完成少量真实数位板试画，确认短排线、拟合精度、保存和重新打开都符合要求。

## 六、常见问题

- **启动后没有打开浏览器**：手动访问 http://127.0.0.1:5317/ 。若仍打不开，查看 `runtime/server.log`；确认文件夹已经完整解压且可以写入。
- **提示端口被占用**：关闭之前启动的便携版再启动。不会自动切换端口，以免看起来像作品库丢失。不要结束不认识的其他程序。
- **复制到同一台电脑的另一处后不能关闭服务**：使用最初启动服务的那份文件夹中的“关闭工具.cmd”。移动整个文件夹前先关闭服务。
- **作品库是空的**：检查浏览器、用户配置及地址是否改变。用备份的完整工程文件重新打开。
- **要查看参考照片**：在工具外自行打开照片；本工具不保存参考图。
- **能否几十台电脑共享一个网站**：当前导出依赖每台电脑的本地服务，请把完整工具文件夹分发到各电脑分别运行。仅部署 `app/` 静态文件不能使用当前导出功能。集中上传、账号和班级管理需要后续开发。

## 七、修改源代码或在 macOS/Linux 上运行

免安装版附带的运行组件仅供运行网站，不包含 npm 开发工具。修改代码时，请安装 Node.js 22.12 或更新的 LTS 版本，从 https://nodejs.org/ 获取。

在 `source/` 目录中运行以下命令，首次安装依赖需要联网：

```sh
npm ci
npm test
npm run portable:check
npm run dev
```

开发服务默认使用 5173 端口。在 macOS/Linux 上也可以按此方式运行；或者安装 Node.js 后，在整个迁移包目录运行 `node runtime/server.mjs`，使用同样的 5317 地址。后者保持命令窗口打开，按 Ctrl+C 结束。

修改后运行 `npm run build`，构建产物在 `source/dist/`。关闭便携版服务，将 `source/dist/` 内的全部文件复制到上级 `app/` 中并覆盖同名文件，随后重新启动。修改 `source/portable/` 中的启动器代码后，也需同步相应文件到 `runtime/`。

源码阅读顺序：`src/model.ts` 数据结构与排序，`src/fitting.ts` 贝塞尔拟合，`src/Canvas.tsx` 绘画交互，`src/App.tsx` 界面，`src/storage.ts` 本机保存，`src/history.ts` 撤销重做。
